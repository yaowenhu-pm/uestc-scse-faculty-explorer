# 教师目录界面实现方案

## 目标与设计依据

采用已确认的 [Figma 三列版](https://www.figma.com/design/bjCcjNHALNZJ6zDPpiOuy3?node-id=3-279)。白色背景、深蓝文字、灰绿色交互；只在首页展示教师姓名、职称、院系、研究方向和证据等级。评分细项、证据摘录与方法说明保留在详情和说明页。

Figma 原生图层和预览已在设计阶段导出。桌面参考尺寸1440px，内容宽1248px，页头96px，卡片三列、间距20px、最低高度218px。研究方向使用实际公开数据，不在代码中写死设计稿示例。

## 实施范围

1. `index.html` / `styles.css`：精简页头、目录工具栏、搜索、职称和等级下拉框、院系导航、三列卡片、轻量页脚。删除原首页大标题、概览统计、侧栏和重复方法介绍。
2. `faculty.js`：集中实现筛选、检索和排序。默认 S → A → B → C → D → E，同等级按证据分降序，相同分数按官网目录顺序。保留姓名与学院目录排序。
3. `app.js`：延续详情弹窗、官网链接、查询参数、筛选移除与清空、空态、加载失败重试。首屏6张卡片，每次再加载12张。
4. 响应式：1100px及以下双列与换行工具栏；640px及以下单列、搜索独占一行、院系横向滚动。长姓名与院系自然换行，卡片研究方向最多两行，完整信息在详情中查看。
5. 可访问性：原生下拉框和按钮、筛选按下状态、结果状态播报、明显键盘焦点、Enter/空格打开详情、Escape关闭并恢复焦点，尊重减少动画设置。
6. `methodology.html` 与404页面共用视觉样式。GitHub Actions发布白名单增加新的公开逻辑模块。

## 数据边界

沿用当前189位教师的公开JSON，不重采集、不修改评级、不发布完整数据库。邮箱、电话、办公地点、完整履历、原始HTML、浏览器状态继续排除在公开网站之外。首页页脚链接至方法说明，明确等级仅反映官网公开证据。
