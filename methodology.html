等级从哪里来

只标注官网研究证据的强度。默认按 S → E 排列，同等级按证据分降序。

先核对证据，再计算等级

逐人阅读官网快照，提取项目、代表成果、研究荣誉及其时间。每项记录分档理由和原文摘录，再由固定规则计算分数。不设各级人数比例，不按页面长度、论文总量或头衔出现次数加分。

只认本人明确的角色：参与不等于主持，子课题不等于总项目，合作者的荣誉不算本人。论文必须能定位到具体作品；未说明含义的作者星号，不推定为通讯作者。同一个奖项或人才基金不重复计入不同主体维度。

取满足全部条件的最高等级。分数高但门槛未满足时，等级不会随分数直接上升；因此 A 级分数可能高于 S 级，页面仍先按等级排序。等级和分数只在本规则内可比。

A、B 级内再细分

先满足大等级的证据门槛，再按固定分数线标注加减档；不按人数或百分位分配。

A、B 级内的固定分数区间
大等级减档中档加档
AA−：60–64A：65–74A+：75 及以上
BB−：35–44B：45–54B+：55 及以上

默认顺序为 S → A+ → A → A− → B+ → B → B− → C → D → E，同档按分数降序。即使 B+ 分数高于 A−，也不能越过 A 的证据门槛；S、C、D、E 不再细分。

加减档仅区分同一大等级内的得分位置，不改变 v2 的基础评分、证据或 2026-09-01 快照。筛选“全部 A 级”仍包含 A+、A、A−，也可单独筛选各档。

作品场所与贡献

代表成果采用项目公开的场所清单，以及能够明确核对的 CCF A 类目录记录。只有期刊名、顶会总量、影响因子或未说明贡献的论文列表，不能进入高档。论文列表里的本人英文全名、页面内可交叉核对的缩写或明确的通讯作者说明，均保留相应依据。

会议的 workshop、short、demo、findings 等记录不自动作为正式代表论文。场所分类是取证口径，不能证明单篇论文质量；跨学科作品及官网未充分说明的贡献仍可能被低估。完整清单、分档细节和复核流程见 完整规则。

快照、复核与补充

189 位教师的数据来自学院官网目录及详情页，快照为 2026-09-01。本次于 2026-09-21 采用 AI 辅助逐条复核并更新规则，没有重新抓取官网，也没有合并外部学术数据库。代码检查引文定位、评分门槛、字段边界和默认排序；语义判断仍可能出错。

未列出不代表没有，低等级也不代表教师水平低。这套标注不评价教学、指导体验或人格，不代替阅读近期论文与直接交流。不同网页的更新程度会影响结果。

欢迎通过 GitHub Issue 或 PR 补充官网链接、原文、时间和本人贡献说明；更正依据后可重算等级。公开数据不包含联系方式、完整履历和原始网页。
